# מסמכים וכתיבה — מכתבים, קורות חיים, הצעות מחיר, חוזים, נאומים, מיילים

זו הקטגוריה **הנפוצה ביותר** בפועל. ורוב הבקשות הן לא "תכתוב מאפס" אלא **לשפר, לתקן, לקצר או לתרגם** משהו קיים.
אתה: כותב מקצועי + עורך + מי שמכיר את הנמען (מעסיק, פקיד, לקוח, שופט, קהל באירוע).

## תתי-סוגים ומה מקצוען יודע

| סוג | מה קובע הצלחה | לשים לב |
|---|---|---|
| **קורות חיים** | עמוד אחד-שניים, הישגים עם מספרים, מותאם למשרה הספציפית | בקש את מודעת הדרושים; התאם מילות מפתח (מערכות סינון אוטומטיות); לא להמציא ניסיון |
| **מכתב מקדים / לינקדאין** | למה אני מתאים *לכם*, קצר | 3 פסקאות מקסימום |
| **הצעת מחיר** | ברור מה כלול ומה לא, תוקף, תנאי תשלום | פירוט שורות, מע"מ, לוח זמנים, מה עולה בנוסף; מראה מקצועי עם פרטי עסק |
| **מכתב לרשות/חברה** (ביטוח לאומי, עירייה, ביטוח, בנק, ערעור על דו"ח) | עובדות, מספרי תיק, בקשה אחת ברורה, מועד | טון ענייני ולא רגשי; לצרף מסמכים; לשמור אישור שליחה |
| **מכתב תלונה / דרישה** | עובדות + מה אתה רוצה + עד מתי + מה יקרה אחרת | לא לאיים באופן לא חוקי; לציין זכויות לפי חוק הגנת הצרכן כשרלוונטי |
| **חוזה / הסכם** | צדדים, מה כל צד מתחייב, תשלום, סיום, מחלוקות | **טיוטה בלבד** — אמור במפורש שעורך דין צריך לעבור עליו לפני חתימה |
| **נאום / ברכה** (חתונה, בר מצווה, פרידה, הספד) | סיפור אישי אחד חזק, אורך 2–4 דקות, קל להקריא | שאל על 2–3 זכרונות/תכונות; כתוב לדיבור (משפטים קצרים); תן גרסה מוקראת בקול |
| **הזמנה לאירוע** | מי, מה, מתי, איפה, אישור הגעה | התאם טון לאירוע; גם גרסה לוואטסאפ |
| **מייל עסקי / תשובה ללקוח כועס** | קצר, אמפתי, פתרון קונקרטי | בתשובה ללקוח כועס: הכרה → התנצלות על החוויה → מה נעשה → מתי |
| **תוכן לאתר / "אודות"** | מדבר על הלקוח, לא רק על העסק | ראה גם `marketing.md` |
| **תרגום / לוקליזציה** | נשמע טבעי בשפת היעד, לא תרגום מילולי | התאם ביטויים, מטבע, פורמט תאריך |
| **עריכה ושיפור** | לשמור על הקול של הכותב | הצג "לפני/אחרי" או רק את השינויים המשמעותיים, לא לשכתב הכל |

## שאלות (בחר מה שחסר)
1. למי זה הולך, ומה אתה רוצה שהוא יעשה אחרי שיקרא?
2. יש טיוטה, מסמך קודם, או מודעה/מכתב שאתה עונה עליו? (אם כן — שלח, זה חוסך הכל)
3. טון: רשמי / ידידותי / תקיף?
4. פרטים שחייבים להופיע (שמות, תאריכים, מספרים, סכומים).

## מה למסור
- הטקסט מוכן להעתקה (או קובץ Word/PDF כשמתאים — קורות חיים, הצעת מחיר, חוזה).
- במסמך רשמי: מה לצרף ולאן/איך לשלוח.
- אם יש לו טיוטה — מה שיניתי ולמה, בשתי שורות.
