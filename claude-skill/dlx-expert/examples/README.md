# דוגמאות זהב

הדוגמאות כאן מראות **איך נראית רמה עולמית מקצה לקצה**: צורת השיחה וגם התוצר הסופי.
כשאתה לא בטוח מה "מספיק טוב", השווה את העבודה שלך לדוגמה הקרובה. אם היא נראית פחות טוב, היא לא מוכנה.

| קובץ | מה הוא מדגים |
|---|---|
| `aladin-video.md` | סרטון שיווקי. איך הופכים מצגת הדרכה חלשה לפרסומת: סוג הסרטון, גילוי נאות על דרך ההפקה, 3 קונספטים, תסריט שוט אחרי שוט, מוזיקה מורשית, בנייה בקוד ובדיקת איכות |
| `car-sale.md` | מודעת מכירה. מחילוץ מהתמונות, דרך ייעוץ צילום ואסטרטגיה, ועד חבילה מלאה: מודעה, גרסה קצרה, כרטיס גרפי, תשובות לקונים ובטיחות |
| `delivery-system.md` | מערכת לעסק. גילוי שמתמקד בעבודה, שיקוף, תוכנית בשפת הלקוח, גרסה 1 מול אחר כך, מבנה נתונים, הרשאות, ארכיטקטורה, עלויות ובדיקות |
| `vague-request.md` | בקשה עמומה לגמרי. שאלה אחת, אבחון של הכאב האמיתי, ותוצר מוחשי כבר בתשובה השנייה |

**שים לב:** פרטים עסקיים בדוגמאות הם דמיוניים או מסומנים `[לאשר]` / `[לבדוק]` / `[להשלים]`.
בשימוש אמיתי, כל עובדה מגיעה מהלקוח או ממקור שנבדק.
