# DLX Expert: Skill ל-Claude

ה-Skill הזה הופך משפט פשוט של אדם בלי ידע מקצועי לתוצר ברמה של צוות מומחים:
מודעות, שיווק, סרטוני פרסומת, תמונות, אתרים, חנויות ומערכות עסקיות.

המשתמש רק כותב מה הוא רוצה, למשל "אני רוצה למכור את הרכב" (עם תמונות), "תבנה לי חנות לאלקטרוניקה"
או "יש לי חברת משלוחים ואני צריך מערכת". מכאן Claude:
1. מזהה את התחום וטוען את המדריך המקצועי המתאים.
2. חוקר את הנושא בעצמו (כולל חיפוש ברשת כשאפשר) ובונה תמונה כוללת.
3. שואל מעט שאלות פשוטות, עם אפשרויות לבחירה, כולל מה רמת הציפייה.
4. מציג כיוון או תוכנית בשפה פשוטה, בונה, בודק את עצמו ומוסר תוצר מוכן לשימוש עם הצעד הבא.

## איך מתקינים

- **ב-Claude (אתר או אפליקציה):** דוחסים את התיקייה `dlx-expert` לקובץ ZIP ומעלים אותו בהגדרות,
  באזור ה-Skills (המיקום המדויק בתפריט עשוי להשתנות). אפשר גם להשתמש בקובץ `dlx-expert.zip` המוכן.
- **ב-Claude Code:** מעתיקים את התיקייה `dlx-expert` אל `~/.claude/skills/` (לכל הפרויקטים)
  או אל `.claude/skills/` בתוך פרויקט מסוים.
- **בלי Skills (למשל Project ב-Claude):** מדביקים את תוכן `SKILL.md` בהוראות הפרויקט ומעלים את
  קבצי `references` כקבצי ידע.

## איך מרחיבים

כדי להוסיף תחום חדש, מוסיפים קובץ ל-`references/` באותו מבנה (מי המומחים, שאלות, החלטות מקצועיות,
מה למסור, רשימת בדיקה) ושורה בטבלה ב-`SKILL.md`.
