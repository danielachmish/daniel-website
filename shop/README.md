# DLX MOBILE — חנות אביזרי סלולר

חנות סטטית (HTML/CSS/JS, בלי build) שמוגשת בכתובת `/shop/`.

## מה לערוך
| קובץ | מה יש בו |
|---|---|
| `js/config.js` | שם החנות, מספר וואטסאפ, עלות משלוח, סף משלוח חינם, איסוף עצמי |
| `js/products.js` | קטגוריות ומוצרים (שם, מחיר, מבצע, תאימות, צבעים/דגמים, מלאי, תמונה) |
| `terms.html` | תקנון, מדיניות החזרות ופרטיות (תבנית — להשלים פרטי עסק) |
| `css/shop.css` | עיצוב — הצבע הראשי ב-`--accent` |

**תמונות אמיתיות:** שמים קובץ ב-`shop/assets/products/` ומוסיפים למוצר `image: "assets/products/שם.jpg"`.
בלי תמונה מוצג איור אוטומטי לפי הקטגוריה.

## איך ההזמנה עובדת
לקוח מוסיף לסל ← ממלא שם/טלפון/כתובת ← נפתח וואטסאפ עם הודעה מוכנה (פריטים, סכום, פרטים)
למספר שב-`WHATSAPP_NUMBER`. אופציונלי: `ORDER_ENDPOINT` (למשל Formspree) לקבלת עותק במייל.
הסל נשמר בדפדפן של הלקוח.

## הרצה מקומית
`python -m http.server 5500` מתיקיית השורש, ואז `http://localhost:5500/shop/`
