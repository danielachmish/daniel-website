# משאבים חינמיים: מוזיקה, אפקטים, תמונות, גופנים, אייקונים

אין "תשתמש במשהו חינמי" בלי מקור, רישיון ותיעוד. וגם אין "לא מצאתי, אז סינתזתי בקוד".
כל נכס חיצוני עובר את שלושת השלבים: **מוצאים, בודקים רישיון, מתעדים.**

---

## 1. רישיונות: מה מותר בשימוש מסחרי

| רישיון | מסחרי | חובת קרדיט | שינוי מותר | הערה |
|---|---|---|---|---|
| **CC0 / Public Domain** | ✓ | לא | ✓ | הכי בטוח |
| **CC BY** | ✓ | **כן** | ✓ | לתת קרדיט בתיאור או בסוף |
| **CC BY-SA** | ✓ | כן | ✓ | יצירה נגזרת צריכה אותו רישיון. **להימנע בפרסומות** |
| **CC BY-NC / NC-SA / NC-ND** | **✗** | | | **אסור לשימוש עסקי.** אף פעם לא בתוצר של לקוח עסקי |
| **CC BY-ND** | ✓ | כן | **✗** | אסור לערוך או לחתוך, ולכן לא מתאים למוזיקה בסרטון |
| **רישיון Pixabay / Unsplash / Pexels** | ✓ | לא (מומלץ) | ✓ | אסור למכור את הנכס כמו שהוא, ואסור להציג אנשים מזוהים כממליצים |

**כללים:**
- אם הרישיון לא ברור, **לא משתמשים.**
- תמונות של **אנשים מזוהים** ושל **מותגים או לוגואים** בתוך התמונה: להימנע בפרסומות (נדרש אישור מצולם).
- תוצאות שנוצרו ב-AI (למשל מופיע "Midjourney" בכותרת): לא להציג אותן כצילום אמיתי, ולא להשתמש בהן כשנדרש צילום אותנטי.
- **מוזיקה מסחרית מוכרת** (שירים מהרדיו): אסור, גם אם "זה רק לאינסטגרם".

## 2. מקור ראשי שעובד מקוד: Openverse (בלי מפתח)

מנוע חיפוש פתוח לתמונות ולשמע ברישיונות פתוחים (Jamendo, Freesound, Flickr, Wikimedia ועוד).
כל תוצאה מגיעה עם רישיון, יוצר וקישור. **נבדק ועובד:**

```bash
# מוזיקה לשימוש מסחרי (מחזיר CC0 / BY / BY-SA בלבד)
curl -s "https://api.openverse.org/v1/audio/?q=upbeat+corporate&license_type=commercial&page_size=10"

# אפקטים קוליים ב-CC0 בלבד (בלי חובת קרדיט)
curl -s "https://api.openverse.org/v1/audio/?q=whoosh&license=cc0&page_size=10"

# תמונות שמותר להשתמש בהן מסחרית ולערוך
curl -s "https://api.openverse.org/v1/images/?q=warehouse&license_type=commercial,modification&page_size=10"
```

**שדות חשובים בתוצאה:** `title`, `creator`, `license`, `license_version`, `url` (הקובץ), `foreign_landing_url`
(העמוד המקורי), `source`, `duration` (באודיו, במילישניות).

**תהליך:**
1. מחפשים לפי **רגש וסגנון** ("cinematic uplifting", "minimal tech", "warm acoustic"), לא לפי "מוזיקה טובה".
2. מסננים: רישיון מסחרי, אורך מתאים, ובמוזיקה **לא BY-ND** (כי עורכים אותה).
3. מורידים 3–5 מועמדים ובודקים: `ffprobe` (אורך, איכות), ומאזינים או בודקים בספקטרוגרמה שזו מוזיקה אמיתית
   ולא שקט או רעש.
4. בוחרים לפי התאמה לקצב העריכה.
5. **מתעדים** בקובץ `CREDITS.md` ליד התוצר: כותרת, יוצר, רישיון, קישור למקור.

הערה: קובצי Jamendo מתקבלים דרך הקישור שב-`url`. אם הורדה ממקור מסוים נחסמת (קורה ב-Freesound בחלק מהסביבות),
עוברים למועמד ממקור אחר. **לא מסנתזים כתחליף.**

## 3. מקורות נוספים (באתר, כשאפשר לגלוש או כשהלקוח מוריד בעצמו)

| סוג | מקורות | רישיון |
|---|---|---|
| **מוזיקה** | Pixabay Music, YouTube Audio Library, Free Music Archive (לסנן רישיון), Jamendo | לבדוק לכל קטע |
| **אפקטים קוליים** | Freesound (לסנן CC0), Pixabay Sound Effects | לבדוק לכל קובץ |
| **תמונות** | Unsplash, Pexels, Pixabay, Wikimedia Commons | רישיון האתר / CC |
| **וידאו (B-roll)** | Pexels Videos, Pixabay Videos, Mixkit | רישיון האתר |
| **גופנים** | Google Fonts (נבדק, עובד). עברית: Heebo, Assistant, Rubik, Frank Ruhl Libre, Secular One, Suez One | OFL, מותר מסחרית |
| **אייקונים** | Lucide, Heroicons, Tabler Icons, Phosphor | MIT / ISC |
| **איורים** | unDraw, Open Peeps, Humaaans (להשתמש במשורה, ורק בסגנון אחיד) | MIT / CC0 |
| **מוקאפים** | בקוד (CSS 3D, מסגרות מכשיר ב-SVG) עדיף על מוקאפים מורדים | |

אם הגלישה לאתר חסומה בסביבה, נותנים ללקוח **קישור מדויק + שם הקטע + הוראה איפה להחליף**, ומוסרים את התוצר
עם מקום שמור. זה עדיף בהרבה על תחליף זול.

## 4. כלים בתשלום (רק באישור, לפי `SKILL.md`)

כשהלקוח מבקש רמה שהחינמי לא מגיע אליה, מציגים אפשרות אחת או שתיים: מה זה, כמה עולה בערך, ומה ההבדל
בתוצאה. **מחירים משתנים: לבדוק בחיפוש לפני שמציינים מספר,** ואם לא נבדק, לומר "בערך" ולהמליץ לבדוק.
דוגמאות לקטגוריות: כלי יצירת וידאו מבוססי AI, קריינות AI איכותית, ספריות מוזיקה במנוי, מאגרי תמונות פרימיום.

## 5. קובץ CREDITS.md (חובה לכל תוצר עם נכסים חיצוניים)

```markdown
# קרדיטים ורישיונות
| נכס | יוצר | רישיון | מקור | איפה בשימוש |
|---|---|---|---|---|
| "Upbeat Corporate" (מוזיקה) | <יוצר> | CC BY 3.0 | <קישור> | רקע, 0:00–0:30 |
```
אם יש רישיון CC BY: גם **שורת קרדיט מוכנה להדבקה** בתיאור הפוסט או בסוף הסרטון.
