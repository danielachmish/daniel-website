# תבנית פרסומת ב-Remotion: "מהבעיה לפתרון, על הקצב"

מנוע מוכן לסרטון פרסומת אנכי (9:16) בסגנון מושן גרפיקס, שנבנה מהנכסים האמיתיים של הלקוח:
מוצרים חתוכים, צילומי מסך אמיתיים של האתר, לוגו ומוזיקה מורשית. **אל תתחיל מאפס.** תעתיק את התבנית,
תחליף נכסים וטקסטים, ותתאים את הסצנות.

## מה בנוי בה (ולמה)
- **גריד קצב:** כל אירוע ממוקם בפעמות (`b(n)`) לפי ה-BPM של המוזיקה (`scripts/assets/beat_grid.py`).
  משנים `BEAT` לפי השיר, ומזיזים את תחילת השיר כך שהפריים הראשון נופל על פעמה.
- **מבנה:** הוק (מקרו על הבעיה + משיכה לאחור) ← טלפון חזיתי עם האתר האמיתי ← דחיפה פנימה לטופס ההזמנה
  (בתוך האזור הבטוח) ← אישור בניגוב עגול ← מעקב משלוח עד "הגיע" ← שיא (המדף מתמלא על הפעמה, אחרי חצי פעמה
  של שקט) ← מסך סיום של כ-2.3 שניות.
- **טקסט:** `Headline` מופיע על הפעמה ונעלם בחיתוך (בלי דיזולב שחופף לכותרת הבאה), תמיד ברצועה העליונה הבטוחה.
  בזמן דחיפה לטלפון, פס כותרת כהה מכסה את ראש הטלפון, כך שאין טקסט על המסך.
- **טלפון בקוד:** חזיתי, שלם, עם פס סטטוס ואי דינמי, והאתר האמיתי גולל בתוכו.
- **סאונד:** מוזיקה עם "דאקינג" לפני השיא, ואפקט על כל תנועה משמעותית (`Sfx`).
- **גרעין וויניט** על הכל, לאחידות מראה.

## הכנת נכסים (סקריפטים ב-`scripts/assets/`)
1. `site_screens.js`: צילומי מסך נקיים של האתר בגודל טלפון. מציג רק אזור שאין בו מותגים מתחרים.
2. `product_cutout.py`: חיתוך מוצרים מרקע לבן. בודקים כל מוצר על רקע כהה.
3. `logo_on_dark.py`: לוגו לרקע כהה.
4. `beat_grid.py`: BPM ופעמה ראשונה של המוזיקה. מוזיקה רק לפי `references/resources.md`.
5. גופן Heebo מקומי נמצא ב-`public/fonts`. דפדפן הרינדור לא תמיד מגיע ל-Google Fonts.

## הרצה
```bash
cp -r <skill>/templates/remotion-ad ./ad && cd ad && npm i
# נכסים: public/products/*.png, public/site.png, public/logo_dark.png, public/music.wav, public/sfx/*.mp3
node stills.mjs stills 2 45 110 175 235 300 370 430 490   # לוח סצנות מפריימים מרונדרים (שער 3)
node render.mjs out/raw.mp4                                # רינדור מלא
```
אחר כך: מאסטרינג סאונד (loudnorm ל-‎-14 LUFS + limiter ל-‎-1.8 dBTP, ראה `marketing-video.md`), ו-`qa_video.sh`,
ו-`qa_crop.sh` על הטלפון, ו**מבקר נפרד** על כל דפי `review/`.

## גבולות התבנית (לומר ללקוח מראש)
- אין בה אנשים. **השיא הרגשי** (בעל עסק שמחייך מול מדף מלא) דורש צילום אמיתי של הלקוח, או שוטים מכלי וידאו
  מבוסס AI (בתשלום, באישור). התבנית בנויה כך שאפשר להחליף סצנה ב-`<OffthreadVideo>` של שוט כזה.
- טופס ההזמנה ומסך האישור **משוחזרים בסגנון האתר** כשההזמנה האמיתית דורשת התחברות. אומרים את זה במסירה.
