# תבניות מסמכים ומצגות בעברית: קורות חיים, הצעת מחיר, מכתב/ערעור, מצגת

מחוללים שמייצרים מסמך עברי מקצועי מקובץ JSON, ומרנדרים ל-PDF. **אל תבנה docx או pptx ביד.** תעתיק דוגמה,
תחליף את התוכן, תריץ, ותבדוק. כל מה שקשה בעברית כבר פתור בקוד, ונבדק ברינדור.

## מה בנוי (ולמה)
- **RTL אמיתי:** כל פסקה `w:bidi`, כל טבלה `w:bidiVisual` (העמודה הראשונה מימין), כל קטע עברי עם גודל, הדגשה
  וגופן של complex-script (`szCs`, `bCs`, `cs`). בלי זה Word מציג את העברית בגודל אחר ממה שראית.
- **כיווניות מתוקנת אוטומטית** (`scripts/hebrew_text.py`): `B.Sc.`, `C++`, `C#`, טלפון `+972`, רשימות עם `·`,
  וטווחי שנים בכיוון אחד. כל באג נבדק ברינדור לפני התיקון.
- **מערכת עיצוב:** Heebo לכותרות, Assistant לגוף, צבע מותג אחד מה-JSON, אפור משני, ריווח 1.15–1.3, A4.
  במצגת: Heebo, 16:9, כותרת-מסר 36pt, טקסט 24pt לפחות, מספרים גדולים 44–54pt.
- **`[לאשר: ...]` / `[להשלים: ...]`** מסומנים בצהוב במסמך ובכתום במצגת. אי אפשר לפספס אותם, ו-`qa_text.py --final`
  נכשל אם נשאר אחד.
- **הצעת מחיר:** החשבון נעשה בקוד (שורות, סה"כ, מע"מ 18%, סה"כ לתשלום). `"kind": "exempt"` = עוסק פטור, בלי
  שורת מע"מ. סעיפים קצרים לא נשברים בין עמודים.
- **קורות חיים:** טור אחד (ATS), תאריכים בקצה השמאלי, הישגים עם תבליטים תלויים.
- **מכתב/ערעור:** פרטי שולח, תאריך, נמען, "הנדון", שורת בקשה מודגשת בראש, עובדות ממוספרות, בקשה במסגרת,
  נספחים, חתימה.
- **מצגת:** סוגי שקפים `title, statement, steps, product, numbers, formula, tiers, table, ask, closing`
  (פירוט בראש `scripts/deck_build.py`). הערות דובר לכל שקף. `product` מצייר מסך מוצר להמחשה עד שיש צילום אמיתי
  (`"image": "path.png"`).

## הרצה
```bash
bash templates/documents/install_fonts.sh                 # פעם אחת בסביבה (Heebo, Assistant, Frank Ruhl Libre)
cp templates/documents/examples/quote.json ./quote.json   # או cv / appeal / deck
python3 scripts/doc_build.py quote.json quote.docx --pdf  # cv | quote | letter  (--safe-fonts = Arial לעריכה ב-Word)
python3 scripts/deck_build.py deck.json deck.pptx --pdf
QA_TEXT_ARGS="--type quote" bash scripts/qa_doc.sh quote.docx qa_quote   # רינדור + qa_text, יוצא 1 על FAIL
```
`--type`: `cv` (עמודים, הישגים עם מספר), `quote` (חשבון ומע"מ), `letter`, `pitch` (מספר שקפים), `deck`.

## דוגמאות (`examples/`)
| קובץ | מה זה | נבדק |
|---|---|---|
| `quote.json` | הצעת מחיר מסטודיו בדיוני לאלאדין: דף נחיתה, 5 פריטים, מע"מ, לא כלול, לו"ז, 40/40/20, אישור | qa_text: 0 FAIL, ציון 23/24 |
| `cv.json` | קורות חיים לג'וניור Full-Stack בדיונית, עמוד אחד | qa_text: 0 FAIL, ציון 22/24 |
| `appeal.json` | בקשה לביטול דוח חניה (תמרור מוסתר) לעירייה | qa_text: 0 FAIL, ציון 23/24 |
| `deck.json` | מצגת משקיעים של 10 שקפים ל-DLX FLOW, כל טענה `[לאשר]` | qa_text: 0 FAIL, ציון 22/24 |

הציונים הם מסבב ביקורת עצמית על התמונות בלבד (לא היה כלי לסוכן-משנה בזמן הבנייה). בעבודה אמיתית: מבקר נפרד.

## מגבלות ידועות
- הרינדור נבדק ב-LibreOffice 24.2. ב-Word אמיתי לא נבדק: עצירת הטאב לתאריכים בקורות החיים, ופרשנות `jc` בפסקה
  RTL, עלולות להיראות שונה. ה-PDF הוא התוצר הראשי.
- מי שיפתח את ה-docx בלי הגופנים יראה גופן חלופי. לעריכה אצל הלקוח: `--safe-fonts`.
- בדיקת החריגה בשקפים מעריכה שבירת שורות לפי מטריקות Heebo וריווח 1.2. היא שמרנית, ולא מחליפה הסתכלות.
- הגופנים ברישיון SIL OFL 1.1 (קבצי `OFL-*.txt`). מותר לשימוש מסחרי ולהטמעה ב-PDF.
