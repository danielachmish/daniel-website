# תבנית גרפיקה לרשתות ולאתר: מנוע HTML → PNG

מנוע מוכן לפוסטים, סטוריז, קרוסלות, מודעות מבצע, פוסט ציטוט לקוח ובאנר לאתר (כולל גרסת מובייל), מעברית
מימין לשמאל, בגופן Heebo מקומי. הוא נבנה מהנכסים האמיתיים של הלקוח (צילומי מוצר חתוכים, לוגו, צבעים).
**אל תתחיל מאפס.** תעתיק את התבנית, תמלא `brand.json` ו-`content.json`, ותרנדר את כל הגדלים בפקודה אחת.

## מה בנוי בה (ולמה)
- **ערכת מותג אחת** (`brand.json`): צבעים, גופן, לוגו לרקע כהה (ובהיר אם יש). לפני רינדור המנוע **מחשב ניגודיות**
  לכל צמד צבעים שהפריסות משתמשות בו, ועוצר אם משהו מתחת ל-4.5:1.
- **אזורים בטוחים לכל פלטפורמה** (`formats.json`): פיד 4:5, ריבוע, סטורי 9:16 (עליון 14%, תחתון 35%, צדדים 6%),
  טיקטוק (גם 13% מימין), באנר 1920×800, ו-1200×628. כל פריסה ממקמת טקסט ולוגו רק בתוכם.
- **6 פריסות** (`layouts/`):
  | פריסה | למה | הערות |
  |---|---|---|
  | `product-hero` | פוסט מוצר 4:5 או ריבוע | מוצר אחד, כותרת, 2–3 מפרטים, הנעה לפעולה |
  | `story` | סטורי/רילס 9:16 | מוצר ראשי מוטה לפנים ושניים מאחור, על פסי המותג. טקסט רק באזור הבטוח |
  | `promo` | מבצע/הנחה 4:5 | רקע בצבע המותג. ערך לא מאושר: `"pending": true` מצייר מסגרת מקווקוות ותגית [לאשר] |
  | `testimonial` | ציטוט לקוח 4:5 | `variant: "accent"` לרקע בצבע המותג. רק ציטוט אמיתי באישור. עד אז: מקום שמור מסומן |
  | `carousel` | קרוסלה של כמה שקפים | נבנית כקנבס רחב אחד ונחתכת, אז המדף ופסי המותג עוברים בין השקפים. סוגי שקף: `cover`, `range`, `number`, `overlap`, `compare`, `cta` |
  | `banner` | באנר לאתר 1920×800 | באותה פריסה בפורמט `feed-4x5` יוצאת **גרסת המובייל** של אותו באנר. תמיד מוסרים את שתיהן |
- **עברית ומספרים:** בטקסט ב-`content.json`: `*מילה*` צובע בצבע המותג, `` `65W` `` מבודד רצף משמאל לימין
  (מספרים, אנגלית ונקודה בסוף), `[לאשר]` מסומן אוטומטית בקו מנוקד כמקום שמור. חץ `←` בסוף הנעה לפעולה הופך לחץ מצויר.
- **המוצר תמיד אמיתי:** `product()` ו-`lineup()` מציגים את הצילום כמו שהוא, באותו קנה מידה לכל האריזות בשורה
  (מוצר "ראשי" מודגש באור ובמיקום, לא בגודל), ולא מגדילים יותר מ-1.1× מהמקור.
- **אלמנט מותג חוזר:** `slashes()` (הפסים המשופעים מהלוגו של הלקוח) ו-`eyebrow()` עם הסימן הקטן. מחליפים לפי המותג.

## הכנת נכסים (`scripts/assets/`)
1. `product_cutout.py <out> p1.png ...`: חיתוך מוצרים מרקע לבן, כולל צל שנופל על הרקע. **בודקים כל חיתוך על רקע
   מג'נטה** (חור בתוך המוצר, כמו כבל לבן בחלון שקוף שנעלם, נראה מיד) **ועל רקע כהה.** חור = מוצר שהשתנה = לא שולחים.
2. `logo_on_dark.py`: לוגו לרקע כהה. על רקע בצבע המותג המנוע צובע אותו שחור (`mono: 'dark'`) אם אין גרסה בהירה.
3. צילומי מוצר ברזולוציה נמוכה (פחות מכ-600px גובה) מגבילים את הגודל על המסך. אומרים ללקוח שצילום אריזה
   ברזולוציה גבוהה הוא השדרוג הגדול ביותר.

## הרצה
```bash
cp -r <skill>/templates/social-graphics ./graphics      # או להריץ ישירות מהסקיל עם תיקיית פרויקט
mkdir -p proj/assets && cp products/*_cut.png logo_dark.png proj/assets/
cp graphics/example/*.json proj/                         # ולמלא לפי הלקוח
node graphics/render.mjs proj                            # כל הגדלים: proj/out/*.png
python3 -I <skill>/scripts/qa_image.py proj/out --out proj/qa   # חייב להסתיים בלי FAIL
```
- צריך Node ו-Playwright (`npm i -g playwright && npx playwright install chromium`). המנוע מוצא גם התקנה גלובלית.
- `--only <id>` מרנדר יצירה אחת.
- ליד כל PNG נשמרים ב-`out/.qa/`: ה-HTML, מדידה של כל שורת טקסט (`.layout.json`), ורינדור של הרקע בלי טקסט (`.bg.png`).
  מהם `qa_image.py` מודד ניגודיות על הפיקסלים האמיתיים, אזורים בטוחים, גודל טקסט, חפיפות, גלישה והגדלת מוצר.

## אחרי הבדיקה הטכנית
מבקר נפרד (סוכן-משנה) מקבל **רק** את `out/*.png`, את `qa/*_phone.png`, את `qa/blur_sheet.png`, את `qa/qa_report.md`,
את התדריך ואת "רף הסוכנות" מ-`references/visuals.md`, ונותן ציון. מתחת ל-20/24: מתקנים ומבקרים שוב. מתקנים, לא מוחקים.

## גבולות התבנית (לומר ללקוח מראש)
- **אין בה אנשים וצילום סביבה.** פוסט עם אדם אמיתי (בעל חנות מול המדף) דורש צילום של הלקוח, או רקע מכלי AI
  (בתשלום, באישור, ובלי שה-AI נוגע במוצר, בטקסט או בלוגו).

- **ציטוטים, מחירים, הנחות ותאריכים** מגיעים רק מהלקוח. עד אז הם מקום שמור מסומן.
