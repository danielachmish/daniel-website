# אתר חמ"ד אוהל מאיר: מדריך קצר

## מה יש בתיקייה
- `index.html`: דף הבית
- `about.html`: החזון, דבר המנהלת והצוות
- `learning.html`: מרחבי בחירה ותוכניות
- `year.html`: מעגל השנה
- `news.html` ו-`news/`: הידיעות עם התמונות (52 ידיעות מהאתר הקודם)
- `parents.html`: טפסים, תקנון, קישורי למידה, גלישה בטוחה ותשלומים
- `contact.html`: פרטי קשר וטופס פנייה
- `accessibility.html`, `privacy.html`, `404.html`: עמודי חובה
- `assets/docs/`: הטפסים להורדה. כדי להחליף טופס, שמים קובץ חדש באותו שם.
- `functions/api/lead.js`: קולט את טופס יצירת הקשר ושולח אותו למייל או לגיליון.

## לפני שהאתר עולה לאוויר (רשימת "לאשר")
כל מקום שמסומן באתר בצהוב "לאשר:" מחכה לבית הספר:
1. האם טליה בר היא עדיין המנהלת (דף הבית ועמוד "עלינו").
2. מכתב מנהלת עדכני (המכתבים באתר הם מתשע"ט–תשפ"ב).
3. רשימת הצוות לשנה הנוכחית (הרשימה באתר מתשפ"ב, בלי מספרי טלפון).
4. חלוקת הכיתות לשנה הנוכחית.
5. לוח האירועים של השנה הנוכחית (עמוד מעגל השנה).
6. קישור ופירוט לתשלומי הורים.
7. שעות הפעילות של המזכירות.
8. שם ופרטי רכז/ת הנגישות, ותאריך עדכון הצהרת הנגישות.
9. אישור נוסח מדיניות הפרטיות.
10. אישור שאפשר לפרסם את תמונות התלמידים (הן פורסמו באתר הקודם, ולפי אישורי הפרסום של ההורים).

## העלאה לאוויר: Cloudflare Pages (חינם, והטופס עובד)
1. פותחים חשבון חינמי ב-github.com על שם בית הספר, יוצרים מאגר פרטי ומעלים אליו את כל התוכן של התיקייה הזו.
2. פותחים חשבון חינמי ב-dash.cloudflare.com, ונכנסים ל-Workers & Pages, Create, Pages, Connect to Git ובוחרים את המאגר.
   Framework preset: None. Build command: ריק. Build output directory: `/`.
3. כדי שהודעות מהטופס יגיעו: ב-Settings, Variables and Secrets מוסיפים `LEAD_WEBHOOK_URL` (למשל Google Apps Script שמכניס כל פנייה לגיליון),
   או `RESEND_API_KEY` + `LEAD_TO_EMAIL` + `LEAD_FROM_EMAIL` לשליחה במייל.
4. בקובץ `contact.html` מוחקים את `data-demo="true"` מהטופס (כרגע הטופס במצב הדגמה ולא שולח).
5. דומיין: ב-Custom domains מוסיפים את הכתובת של בית הספר, ומחליפים את `ohelmeir.example.co.il` בכל הקבצים בכתובת האמיתית.

## עדכון תוכן
העמודים נוצרים מהקובץ `build.py` (בתיקיית העבודה). עדכון טקסט קטן אפשר לעשות ישירות בקובץ ה-HTML ולהעלות אותו מחדש ל-GitHub.
